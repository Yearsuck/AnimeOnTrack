# UI audit — 2026-11-27

Scope: `src/styles.css` (4257 lines) + `src/styles/*.css` (4754 lines), `src/views/**`, `src/components/**`,
`src/i18n/catalog/es.ts` (952 lines). Static review of the code on `develop` (no screenshots: no sandbox was
answering on :9222). Plain CSS + React stays; no Tailwind, no new backend features.

Summary: the foundation is better than the usual audit target. Tokens exist for spacing, radius, type, motion,
focus ring and both themes, inline styles are already gone, and keyboard/dialog handling exists in most places.
The real debt is (1) a ~330-line **accidentally duplicated block** in `styles.css`, (2) **`--muted-2` text and
light-theme semantic colors below AA**, (3) **desktop-only settings visible on Android**, (4) **error states that
only `console.error`**, (5) inconsistent Spanish microcopy, and (6) residual magic values in the per-view CSS files.

## 2. Token proposal (refines `:root`, keeps names)

No renames of existing tokens: add tokens, change a few values, migrate literals.

### 2.1 Value changes (contrast)

```css
/* dark */
:root {
  --muted-2: #7d91a4;            /* was #6b7f92; target >= 4.5 on --surface (confirm in PR) */
  --accent-solid: #d93232;       /* was #e23b3b; white on it ~5.0 */
  --accent-solid-hover: #e84040; /* hover stays brighter than rest; confirm white >= 4.5 */
  --border-strong: #3d5670;      /* NEW: ~3:1 on surface, for control outlines */
}
/* light */
:root[data-theme="light"] {
  --muted-2: #647586;            /* was #8394a5; target >= 4.5 on --surface and --bg */
  --success: #15774f;            /* was #1f9d6b; target >= 4.5 on white and --surface-2 */

  --border-strong: #8a9aab;      /* NEW: ~3:1 on white */
```

The hexes are starting points: the PR must run the same relative-luminance script used for this audit over every
pair in the table and adjust until the targets hold. Rule going forward: `--muted-2` is for text on
`--surface`/`--bg` only; on `--surface-2/3` use `--muted`.

## 5. Notes
- Mobile detection is `/Android/i.test(navigator.userAgent)` in `src/lib/platform.ts`, which also sets
  `html[data-platform="mobile"]` (`main.tsx:17`); CSS rules in `mobile.css` are all scoped to it (71 selectors).
  Fine for Tauri Android; a backend `platform()` value would be sturdier if another mobile target ever ships.
- `--accent` red is both brand and "followed" state color, next to the rose `--danger`. Separating brand from
  state is a brand decision, left out of scope.
